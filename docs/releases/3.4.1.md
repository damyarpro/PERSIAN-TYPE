# Persian Type 3.4.1 | پرشین تایپ ۳.۴.۱

## فارسی

این نسخه راهنمای نصب و کار با Persian Type را برای Blender 5.3 و نسخه‌های پشتیبانی‌شده به‌روز می‌کند.

### تغییرات

- **Edit Active Line:** راهنمای ویرایش خط انتخاب‌شده، **Paste** و **Load from Strip** به‌روز شد.
- **Appearance:** در راهنمای Video Sequencer مشخص شده که Blender 5.0.1 کنترل فاصلهٔ خطوط و پیش‌تنظیم استایل ندارد.
- **Mesh Clean:** توضیحات پروژه کاربرد این ابزار در 3D Viewport را مشخص می‌کند.
- **دانلود:** لینک‌های فارسی و انگلیسی به بستهٔ 3.4.1 اشاره می‌کنند.

### مشکلات شناخته‌شده

- موتور شکل‌دهی برای بعضی ترکیب‌های نشانه‌گذاری و متن دوجهته، بازخوانی کاملاً یکسان تضمین نمی‌کند؛ بازشکل‌دهی هنگام Load بررسی می‌شود.
- یای عربی در شکل‌های مشترک به یای فارسی برمی‌گردد.
- وضعیت ویرایش متن سه‌بعدی بین آبجکت‌ها مشترک است. حالت تایپ به‌صورت خودکار خاتمه نمی‌یابد و بازنویسی متن ممکن است قالب‌بندی تک‌حرفی را از بین ببرد. بازنویسی متن و حرکت مکان‌نما با طول متن بیشتر زمان می‌برند.
- نام فونت‌های سیستم از نام فایل گرفته می‌شود و ممکن است نام کامل خانواده را نشان ندهد. نام‌های فارسی در فهرست فونت ممکن است با حروف جدا و ترتیب نادرست نمایش داده شوند.
- استایل مصنوعی Bold/Italic، نبود گرادیان مستقل و ذخیره‌نشدن فاصلهٔ خطوط در preset بلندر همچنان برقرار است.

فایل `persiantype-3.4.1.zip` را از مسیر **Edit > Preferences > Get Extensions > Install from Disk** نصب کنید.

### اعتبارسنجی

در پروفایل‌های موقت Windows، Blender 5.0.1 تعداد ۸۵ بررسی و نسخه‌های 5.2.0 LTS و 5.3.0 هرکدام ۸۸ بررسی را بدون شکست پاس کردند. تست‌ها شامل ویرایش متن، فونت‌ها، Mesh Clean، اپراتورهای Video Sequencer، ذخیره و بازیابی استایل در نسخه‌های پشتیبان، رندر واقعی استریپ و ثبت و لغو ثبت افزونه بودند. رابط گرافیکی، macOS و Linux و چرخهٔ کامل حالت تایپ تعاملی تست نشدند.

## English

This release updates the Persian Type installation and workflow guide for Blender 5.3 and other supported versions.

### Changes

- **Edit Active Line:** Updated the instructions for editing the selected line, **Paste**, and **Load from Strip**.
- **Appearance:** The Video Sequencer guide identifies the line-spacing and style-preset controls that Blender 5.0.1 lacks.
- **Mesh Clean:** The project description identifies this as a 3D Viewport tool.
- **Download:** The Persian and English links point to the 3.4.1 package.

### Known issues

- Some punctuation/mixed-direction strings do not guarantee exact logical read-back; Load checks re-shape stability.
- Shared Arabic Yeh presentation forms resolve to Persian Yeh.
- 3D text objects share the edit buffer. Typing mode does not finish automatically, and rewriting text may clear per-character formatting. Rewriting and caret movement can slow down with longer text.
- System font labels come from filenames and may omit the full family name. Persian names in font lists may appear disconnected or out of order.
- Synthetic strip Bold/Italic, no independent gradient, and omitted line spacing in Blender style presets remain.

Install `persiantype-3.4.1.zip` through **Edit > Preferences > Get Extensions > Install from Disk**.

### Validation

Windows, isolated profiles: 85 passed checks on Blender 5.0.1; 88 on 5.2.0 LTS; 88 on 5.3.0; zero failures. Includes text editing, fonts, mesh cleanup, sequencer operators, preset save/restore where available, real strip rendering and registration cleanup. Native GUI interaction, macOS/Linux and the full modal lifecycle were not tested.
