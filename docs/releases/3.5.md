# Persian Type 3.5 | پرشین تایپ ۳.۵

## فارسی

Persian Type 3.5.0 به Blender 5.3.0 یا جدیدتر نیاز دارد. برای Blender 5.0.1 یا 5.2 از [نسخهٔ 3.4.1](https://github.com/damyarpro/PERSIAN-TYPE/releases/tag/v3.4.1) استفاده کنید.

### مشکلات شناخته‌شده

- موتور شکل‌دهی برای بعضی ترکیب‌های نشانه‌گذاری و متن دوجهته، بازخوانی کاملاً یکسان تضمین نمی‌کند؛ بازشکل‌دهی هنگام Load بررسی می‌شود.
- یای عربی در شکل‌های مشترک به یای فارسی برمی‌گردد.
- وضعیت ویرایش متن سه‌بعدی بین آبجکت‌ها مشترک است. حالت تایپ به‌صورت خودکار خاتمه نمی‌یابد و بازنویسی متن ممکن است قالب‌بندی تک‌حرفی را از بین ببرد. بازنویسی متن و حرکت مکان‌نما با طول متن بیشتر زمان می‌برند.
- نام فونت‌های سیستم از نام فایل گرفته می‌شود و ممکن است نام کامل خانواده را نشان ندهد. نام‌های فارسی در فهرست فونت ممکن است با حروف جدا و ترتیب نادرست نمایش داده شوند.
- استایل مصنوعی Bold/Italic، نبود گرادیان مستقل و ذخیره‌نشدن فاصلهٔ خطوط در preset بلندر همچنان برقرار است.

فایل [`persiantype-3.5.0.zip`](https://github.com/damyarpro/PERSIAN-TYPE/releases/download/v3.5/persiantype-3.5.0.zip) را از مسیر **Edit > Preferences > Get Extensions > Install from Disk** نصب کنید.

### اعتبارسنجی

در Blender 5.3.0 روی Windows، مانیفست و زیپ اعتبارسنجی شدند. همین زیپ ۸۸ بررسی شامل متن سه‌بعدی، فونت‌ها، Mesh Clean، سکوئنسر و رندر فارسی را بدون شکست گذراند. نصب و فعال‌سازی مجدد در پروفایل تازه موفق بود. Blender 5.2.0 LTS نصب بسته را به‌دلیل نیاز به نسخهٔ 5.3.0 رد کرد.

## English

Persian Type 3.5.0 requires Blender 5.3.0 or later. For Blender 5.0.1 or 5.2, use [version 3.4.1](https://github.com/damyarpro/PERSIAN-TYPE/releases/tag/v3.4.1).

### Known issues

- Some punctuation/mixed-direction strings do not guarantee exact logical read-back; Load checks re-shape stability.
- Shared Arabic Yeh presentation forms resolve to Persian Yeh.
- 3D text objects share the edit buffer. Typing mode does not finish automatically, and rewriting text may clear per-character formatting. Rewriting and caret movement can slow down with longer text.
- System font labels come from filenames and may omit the full family name. Persian names in font lists may appear disconnected or out of order.
- Synthetic strip Bold/Italic, no independent gradient, and omitted line spacing in Blender style presets remain.

Install [`persiantype-3.5.0.zip`](https://github.com/damyarpro/PERSIAN-TYPE/releases/download/v3.5/persiantype-3.5.0.zip) through **Edit > Preferences > Get Extensions > Install from Disk**.

### Validation

Blender 5.3.0 on Windows validated the manifest and ZIP. The package passed 88 checks with zero failures, covering 3D text, fonts, Mesh Clean, the Video Sequencer, and Persian rendering. A fresh install and disable/re-enable cycle passed. Blender 5.2.0 LTS rejected installation because the package requires 5.3.0.
